# 目的
大学受験数学の一問一答カードを、単元ごとに分類して管理する

# ファイルと配列
- 1ファイルを1単元とし、既存のファイル名、変数名、配列形式を維持する
- 各カードは `[問題文, 解答]` の2要素配列にする
- 計算・証明カードの解答には、結論直前の根拠または途中式を含める
- 新しいファイルを作成した場合だけ、上位の `files.js` に登録する

# 追加と並び順
- 問題文と解答がともに完全一致するカードだけを重複とみなし、追加しない
- 問題文または解答が異なる同種カードは残し、既存の類題の直前または直後に置く
- ファイル内は、基本事項、公式、標準問題、応用問題など、内容のまとまりが分かる順序にする
- `//` の分類コメントは大きなまとまりにだけ置き、カードごとの説明には使わない
- 依頼がない限り、既存カードの修正、削除、大規模な並べ替えを行わない

# 確認
- 編集したファイルをJavaScriptとして読み込み、配列として評価できることを確認する
- 全カードが文字列2要素の配列であることを確認する
- 追加した問題文と解答の組が、意図した位置に1件だけ存在することを確認する
