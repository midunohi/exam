# 統合出題

入口は index.html。各科目フラッシュカード、英単語・例文、英文速読4択、フラッシュ暗算、英単語バトルの5形式を出題する。
歯車で形式ごとの出題率を変更する。初期値は各形式1。0は出題なし。1〜10の抽選重みは順に1・2・3・5・8・12・20・30・50・100倍。形式内の問題数は形式間の抽選に影響しない。
設定変更は次回の抽選から有効。全形式が0なら出題待ちとなり、1以上にして設定を閉じると再開する。
人物アイコンでキャラ画面を開閉する。設定やキャラ画面を開いている間は速読と暗算の進行を一時停止する。

## 抽選の区切り

- 各科目カードは1カード。解答表示後に進めると再抽選する。
- 英単語・例文は1語。語義と例文を最後まで表示し、進めると再抽選する。
- 速読は英文1本と4択1問、暗算は数列1組と4択1問。採点結果の表示後に再抽選する。
- 英単語バトルは4択1問。結果表示後に再抽選する。戦闘不能時は再開操作の後に再抽選する。切り替え後も戦闘の途中状態を保つ。

## 実装と保存

開発/schedule.js が形式一覧と抽選、開発/exam.js が画面切替と出題率の保存を担当する。
開発/views/ の形式ごとの .view.js が画面、対応する .js が出題処理を担当する。index.html の iframe 内で動き、開発/view-bridge.js で出題の区切りと表示状態を連携する。
apps/lib/ は共通処理とスタイル。既存の問題データ・画像を読み込む。ビルドは不要。
出題率は exam-mixed-rates-v1 に保存する。経験値と装備は既存の保存キーを使い、GitHub Pagesでは同じ公開元の既存データを読み込む。数式描画は既存の MathJax CDN を使う。
